지원사업, 신청할 수 있는지부터 확인하세요.

스마트공장과 산업안전 지원사업을 현장에서 오래 맡아 온 실무자가 직접 봐드립니다. 신청 가능 여부 진단은 무료이고, 사업계획서가 필요할 때만 정해진 요금으로 도와드립니다.

먼저

신청 가능 여부 진단

무료

회사 정보를 보고 지금 신청할 수 있는 공고와 준비할 서류를 정리해 드립니다.

  • 2영업일 안에 이메일 회신
  • 관심 공고의 자격 요건 확인
계획서를 직접 썼다면

사업계획서 검토

99,000원 VAT 별도

작성하신 계획서를 항목별로 읽고 수정 의견을 드립니다.

  • 문제-해결-성과 연결, 성과지표 점검
  • 5영업일, 수정본 1회 재검토
처음부터 막막하다면

사업계획서 작성 지원

290,000원~ VAT 별도

회사가 제공한 자료와 수치로 계획서 구성과 초안 문장을 함께 만듭니다.

  • 화상 인터뷰 1회로 현장 문제 정리
  • 공고 양식에 맞춘 초안, 수정 2회
이렇게 일합니다 성공보수를 받지 않습니다. 선정 여부와 관계없이 위 고정 요금만 받습니다.
선정을 보장하지 않으며, 신청서 제출은 회사가 직접 합니다.
사실과 다른 내용은 쓰지 않습니다. 모든 수치와 내용은 회사가 제공한 자료를 기준으로 하며, 최종 확인은 회사가 합니다.

결제는 계좌이체로 받고 전자세금계산서 또는 현금영수증을 발행합니다. 작업 범위와 금액을 먼저 확인해 드린 뒤 진행하므로, 신청만으로는 비용이 발생하지 않습니다.

공급기업을 위한 산출물 작성 지원

스마트공장을 구축하는 공급기업(개발사·SI)의 요구사항정의서, 설계서, 테스트결과서, 매뉴얼, 중간·완료 점검 서류를 검토하거나 작성해 드립니다. 개발은 하던 대로, 서류는 맡기세요.

이미 써 둔 산출물이 있다면

산출물 검토

150,000원 VAT 별도 · 과제당

점검 전에 산출물을 읽고 보완할 곳을 짚어 드립니다.

  • 요구사항 → 화면 → 테스트 ID 추적 점검
  • 자주 받는 보완 요청 기준, 3영업일
서류 쓸 사람이 없다면

산출물 작성 대행

400,000원~ VAT 별도 · 7종 기준

개발 내용·화면·테스트 기록을 받아 기관 양식에 맞춰 작성합니다.

  • 요구사항정의서~사용자테스트결과서·매뉴얼
  • 수정 1회, 범위·분량에 따라 견적
점검이 코앞이라면

중간·완료 점검 대응

250,000원~ VAT 별도

점검 제출서류 목록 정리와 중간·완료보고서 초안을 함께 준비합니다.

  • 제출서류 체크리스트, 보완 요청 대응
  • 점검 일정에 맞춘 우선순위 작업
원칙 실제 개발·테스트 내용과 다른 산출물은 작성하지 않습니다. 받은 기록을 정리해 양식에 맞추는 일만 합니다.
도입기업과 공급기업 사이의 계약·선정에는 관여하지 않으며, 점검 통과를 보장하지 않습니다.
작성 예시가 궁금하면 자료실의 개발 산출물 작성 예시를 먼저 보세요.
